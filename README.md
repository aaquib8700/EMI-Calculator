# 🏦 Mortgage / Loan EMI Calculator – React

A simple and interactive **EMI (Equated Monthly Installment) Calculator** built using **React.js**.  
It calculates the monthly EMI amount based on:

- Principal Loan Amount
- Annual Interest Rate
- Loan Tenure in Years

The EMI updates **automatically in real-time** whenever the input values change.

---

## 🚀 Features

- 📥 Input: Principal, Interest Rate, Loan Tenure
- 🔄 Auto EMI calculation using `useEffect`
- 🧮 Uses standard EMI formula
- ⚛️ React functional components + hooks
- 🖩 Rounds EMI to nearest whole value
- 🧑‍💻 Clean & beginner-friendly code
